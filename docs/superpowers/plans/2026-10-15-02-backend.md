# Scanner Saham — Rencana 2: `backend` (Axum + PostgreSQL + Yahoo)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Rencana ini dikerjakan langsung di sesi yang menulisnya, jadi isinya berupa antarmuka, perilaku, dan test yang wajib lolos per task. Kode ditulis langsung ke file saat eksekusi.

**Goal:** REST API untuk scanner: menyimpan emiten dan harga harian di PostgreSQL, mengambil data dari Yahoo Finance (backfill dan update harian terjadwal), menyediakan cache `DataFrame` untuk `scanner-core`, serta CRUD watchlist dan scan tersimpan. Semuanya dijalankan dengan Podman dan `./prod.sh`.

**Architecture:** Crate `backend` (binary + lib untuk integration test). `AppState { pool, cache, ingest, source }` dibagikan ke handler Axum. Ingest memakai trait `PriceSource` (implementasi `YahooSource`, dan implementasi palsu untuk test). Statistik saham dan ringkasan pasar dihitung di `scanner-core` supaya mudah dites tanpa database.

**Tech Stack:** axum 0.8 (fitur `multipart`), sqlx 0.9 (postgres, chrono, migrate, runtime-tokio, tls-rustls), tokio 1, reqwest 0.13 (json, rustls), tower-http 0.7 (fs, cors, trace), tracing, async-trait, csv, anyhow, futures. Podman untuk PostgreSQL 16.

Spec: `docs/superpowers/specs/2026-10-15-scanner-saham-design.md` (bagian 2.3, 3, 5, 7, 8, 9).

## Global Constraints

- Mengikuti batasan Rencana 1. `shared` tetap hanya bergantung pada `serde`.
- Query runtime (`sqlx::query_as` + `FromRow`), **bukan** macro `query!`, supaya build tidak butuh database.
- Migrasi ada di `migrations/` (root) dan dimuat dengan `sqlx::migrate!("../../migrations")`.
- Semua endpoint di bawah `/api`. Error berbentuk `shared::ApiError { error, message }` dengan kode `bad_request` 400, `not_found` 404, `conflict` 409, `unavailable` 503, `internal` 500.
- Tanggal di JSON berformat `YYYY-MM-DD`.
- Podman tanpa compose: container `scanner-saham-db`, image `docker.io/library/postgres:16`, volume `scanner-saham-pgdata`, port host `5440`, user/password/db `scanner`/`scanner`/`scanner`.
- Integration test butuh `DATABASE_URL=postgres://scanner:scanner@localhost:5440/scanner` (`scripts/db.sh start` dulu). `#[sqlx::test]` membuat database sementara per test.
- Perbarui `docs/architecture.md` di akhir rencana.

### Task 1: DTO REST di `shared` + statistik dan ringkasan pasar di `scanner-core`

**Interfaces (Produces):**
- `shared::api`: `ApiError { error: String, message: String }`; `StockDto { ticker, name, sector: Option<String>, board: Option<String>, is_active: bool }`; `StockStatsDto { last_date, close, change_1d, change_1m, change_3m, change_1y, high_52w, low_52w, avg_value_20 }` (semua `Option<f64>`, kecuali `last_date: String` dan `close: f64`); `StockDetailDto { stock: StockDto, stats: Option<StockStatsDto> }`; `CandleDto { date, open, high, low, close, volume: f64 }`; `IndicatorSeriesDto { key, label, values: Vec<Option<f64>> }`; `CandlesDto { candles, series }`; `ImportResultDto { inserted, updated }`; `SaveScanDto { name, rules: ScanRequest }`; `SavedScanDto { id: i64, name, rules, updated_at: String }`; `CreateWatchlistDto { name }`; `WatchlistItemDto { ticker, name, close: Option<f64>, change_pct: Option<f64>, volume: Option<f64> }`; `WatchlistDto { id, name, items }`; `MoverDto { ticker, name, close, change_pct, value }`; `MarketSummaryDto { as_of, advancers, decliners, unchanged, top_gainers, top_losers, top_value }`; `IngestRunDto { id, started_at, finished_at: Option<String>, status, trigger, ok_count: i32, failed_tickers: Vec<String>, error: Option<String> }`; `IngestProgressDto { done, total, failed }`; `IngestStatusDto { current: Option<IngestProgressDto>, history: Vec<IngestRunDto> }`.
- `scanner_core::stock_stats(history: &DataFrame) -> Result<Option<StockStatsDto>, CoreError>` (satu ticker, terurut tanggal; `None` kalau kosong). Periode: 1D = 1 bar, 1M = 21, 3M = 63, 1Y = 250 bar; 52W = high/low maksimum/minimum 250 bar terakhir.
- `scanner_core::market_summary(prices: &DataFrame, meta: &HashMap<String, StockMeta>, top: usize) -> Result<MarketSummaryDto, CoreError>`. Hanya ticker dengan bar terakhir = tanggal terbaru. Naik/turun/stagnan dihitung dari change 1 hari. Gainers/losers hanya untuk avg value 20 hari ≥ `LIQUID_MIN_VALUE`. Top value diurutkan dari `close × volume` hari terakhir.

**Tests:**
- [ ] `stats_basic`: 300 bar naik 1/bar → `change_1d` = (c/c₋₁−1)·100, `high_52w` = high maksimum 250 bar terakhir, `change_1y` ada; 10 bar → `change_1m` = None.
- [ ] `summary_counts_and_tops`: 3 ticker likuid (naik, turun, flat) + 1 tidak likuid naik besar + 1 basi → advancers 2 (termasuk yang tidak likuid), decliners 1, unchanged 1; ticker tidak likuid tidak muncul di gainers; ticker basi tidak dihitung; urutan gainers/losers/value benar.
- [ ] `cargo check -p shared --target wasm32-unknown-unknown` tetap sukses.

### Task 3: Lapisan database + frame + cache

**Interfaces (Produces):**
- `db::stocks`: `upsert_many(pool, &[StockRecord]) -> Result<ImportResultDto>`, `list(pool, q: Option<&str>, limit) -> Vec<StockDto>`, `get(pool, ticker) -> Option<StockDto>`, `active_tickers_with_last_date(pool) -> Vec<(String, Option<NaiveDate>)>`, `fill_name_if_missing(pool, ticker, name)`, `meta_map(pool) -> HashMap<String, StockMeta>`, `count(pool) -> i64`. `StockRecord { ticker, name, sector, board }`; nama kosong → ticker.
- `db::prices`: `upsert_bars(pool, ticker, &[PriceBar])` (batch `UNNEST`, `ON CONFLICT DO UPDATE`), `history(pool, ticker) -> Vec<PriceRow>`, `latest_bars(pool, n) -> Vec<PriceRow>` (window `row_number`, hanya emiten aktif), `is_empty(pool) -> bool`. `PriceBar { date: NaiveDate, open, high, low, close, adj_close: f64, volume: i64 }`; `PriceRow { ticker: String, date, open, high, low, close, adj_close, volume }`.
- `db::watchlists`: `list(pool) -> Vec<(i64, String, Vec<String>)>`, `create(pool, name) -> i64`, `delete(pool, id) -> bool`, `add_item(pool, id, ticker) -> bool` (false kalau watchlist tidak ada), `remove_item(pool, id, ticker) -> bool`, `tickers(pool, id) -> Option<Vec<String>>`.
- `db::scans`: `list`, `create(name, rules) -> SavedScanDto`, `update(id, name, rules) -> Option<SavedScanDto>`, `delete(id) -> bool`. `rules` disimpan sebagai `sqlx::types::Json<ScanRequest>`.
- `db::ingest_runs`: `start(pool, trigger) -> i64`, `finish(pool, id, status, ok, failed: &[String], error: Option<&str>)`, `recent(pool, n) -> Vec<IngestRunDto>`.
- `frame::prices_frame(rows: &[PriceRow]) -> Result<DataFrame>`: kolom sesuai skema input core, harga × `adj_close/close` (faktor 1 kalau close = 0), volume f64, date sebagai `Date`.
- `cache::PriceCache` (`Clone`): `reload(pool, bars) -> Result<()>`, `snapshot() -> Option<Arc<CacheData>>`; `CacheData { prices: DataFrame, meta: HashMap<String, StockMeta> }`.

**Tests (`#[sqlx::test]`):**

### Task 4: Ingest Yahoo + orkestrasi + jadwal

**Interfaces (Produces):**
- `ingest::yahoo::parse_chart(json: &str) -> Result<Fetched, FetchError>`; `Fetched { name: Option<String>, bars: Vec<PriceBar> }`. Tanggal = `timestamp + gmtoffset` → tanggal lokal. Bar dengan OHLC null dibuang. `adjclose` tidak ada → pakai close. Volume null → 0. Respons `error.code == "Not Found"` → `FetchError::NotFound`.
- `#[async_trait] trait PriceSource: Send + Sync { async fn fetch(&self, ticker: &str, from: NaiveDate, to: NaiveDate) -> Result<Fetched, FetchError>; }`. `FetchError { NotFound, RateLimited, Transient(String), Invalid(String) }`.
- `YahooSource::new() -> Self` (reqwest dengan User-Agent browser, timeout 20 detik, URL `{TICKER}.JK`, `period1/period2` unix).
- `ingest::IngestHandle` (`Clone`): `try_begin() -> Option<IngestGuard>` (None kalau sedang jalan), `progress() -> Option<IngestProgressDto>`.
- `ingest::run(pool, source: Arc<dyn PriceSource>, guard, trigger: &str, concurrency, backfill_years, today: NaiveDate) -> Result<IngestRunDto>`: retry 3× (1s/2s/4s, durasi di-inject agar test cepat) untuk `RateLimited`/`Transient`; status `success`/`partial`/`failed`; mengisi nama emiten.
- `ingest::schedule::next_run(now: DateTime<Utc>, at: (u32, u32)) -> DateTime<Utc>`: Senin–Jumat WIB (UTC+7), selalu > `now`.
- `ingest::spawn_scheduler(state)` dan `ingest::trigger(state, trigger) -> Result<IngestRunDto, AppError>` (409 kalau sedang jalan; jalan di background lalu reload cache).

**Tests:**
- [ ] `parse_fixture`: `tests/fixtures/bbca_chart.json` (respons nyata 5 hari) → 5 bar, tanggal benar, nama "PT Bank Central Asia Tbk".
- [ ] `parse_nulls_and_not_found`: bar dengan null dibuang; JSON error Not Found → `NotFound`.
- [ ] `next_run_cases`: Senin 10:00 WIB → Senin 17:00; Senin 17:00 → Selasa 17:00; Jumat 18:00 → Senin 17:00; Sabtu → Senin.
- [ ] `ingest_run_with_fake_source` (`#[sqlx::test]`): 3 emiten, sumber palsu (1 sukses, 1 NotFound, 1 Transient lalu sukses) → status `partial`, ok 2, failed `["XXXX"]`, harga tersimpan, nama terisi, run tercatat di `ingest_runs`; `try_begin` kedua saat guard masih dipegang → None.

### Task 5: REST API

**Interfaces (Produces):**
- `backend::AppState { pool, cache: PriceCache, ingest: IngestHandle, source: Arc<dyn PriceSource>, config: Arc<Config> }` (Clone).
- `backend::build_app(state) -> Router` dengan semua route di spec 5, ditambah `ServeDir` + fallback `index.html` untuk `static_dir` kalau ada, dan CORS permisif untuk dev.
- Parameter chart `indicators=sma:50,ema:20,bb:20:20,rsi:14,macd:12:26:9,supertrend:10:30,stoch:14:3:3,atr:14,adx:14,psar:20:200,ichimoku:9:26:52` → daftar `Indicator` (bb → upper/middle/lower, macd → line/signal/hist, stoch → K/D, ichimoku → 4 garis, adx → ADX/+DI/−DI). Nama tidak dikenal atau parameter salah → 400. Setiap indikator divalidasi dengan `scanner_core::validate::indicator`.
- `range` ∈ `3m|6m|1y|3y|5y` (default `1y`) → 63/126/250/750/1250 bar terakhir.
- `POST /api/scan`: cache kosong → 503 "Data belum tersedia, jalankan update data"; `universe.watchlist_id` → `allowed` dari DB (404 kalau watchlist tidak ada); dijalankan di `spawn_blocking`.
